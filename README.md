# 🎨 CloneX - Modern Portfolio Showcase

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![React](https://img.shields.io/badge/React-19.1-blue)](https://reactjs.org/)
[![Vite](https://img.shields.io/badge/Vite-5.4-purple)](https://vitejs.dev/)
[![TailwindCSS](https://img.shields.io/badge/TailwindCSS-4.1-38BDF8)](https://tailwindcss.com/)

**CloneX** is a cutting-edge portfolio website inspired by the design aesthetics of K72. Built from scratch with a focus on modern web animations and smooth user experiences, this project showcases advanced frontend development techniques using the latest web technologies.

---

## 🚀 Key Features

*   **🎨 Stunning Visuals:** Modern UI with smooth animations and transitions
*   **⚡ Blazing Fast:** Built with Vite for optimal performance
*   **📱 Fully Responsive:** Looks great on all devices
*   **🎬 GSAP Animations:** Advanced scroll-triggered and timeline animations
*   **🖱️ Interactive Elements:** Engaging hover and focus states
*   **🌐 Modern Routing:** Seamless page transitions with React Router
*   **🎨 TailwindCSS:** Utility-first CSS framework for rapid UI development

---

## 🛠️ Tech Stack

### Frontend
- **Framework:** React 19
- **Bundler:** Vite
- **Styling:** TailwindCSS
- **Animations:** GSAP (GreenSock Animation Platform)
- **Smooth Scrolling:** Lenis
- **Icons:** Lucide Icons
- **Routing:** React Router DOM

### Development Tools
- **Package Manager:** npm
- **Linting:** ESLint
- **Version Control:** Git

## ⚙️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/clonex.git
    cd clonex
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    # or
    yarn dev
    ```

4.  Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

### Building for Production
```bash
npm run build
# or
yarn build
```

### Preview Production Build
```bash
npm run preview
# or
yarn preview
```
